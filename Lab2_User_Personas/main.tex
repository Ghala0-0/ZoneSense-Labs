\subsection*{Part 4 -- Scenarios and User Stories}

\subsubsection*{Persona 1 -- Building Resident}

\keephead{Usage Scenario}
During the day, the Building Resident uses ZoneSense to monitor environmental conditions across the building and identify zones that require attention. When an abnormal condition occurs, the Building Resident reviews the affected zone, environmental readings, and alert information. If a supported control action is proposed, an authorized Building Resident reviews the proposal and decides whether to approve or reject it. If approved, the system executes the control action; if rejected, it does not. The Building Resident then continues monitoring the affected zone to determine whether the condition improves.

\keephead{User Stories}
\begin{enumerate}[itemsep=3pt]
\item As a Building Resident, I want to view the environmental condition of each building zone so that I can quickly identify zones that require attention.
\item As a Building Resident, I want to view temperature, \COtwo, humidity, and sound-level readings for each zone so that I can understand its current environmental condition.
\item As a Building Resident, I want to receive alerts that identify the affected zone and abnormal environmental condition so that I can respond promptly.
\item As a Building Resident, I want to review a proposed control action for a controllable abnormal condition so that I can decide whether it should be executed.
\item As a Building Resident, I want to approve or reject a proposed control action so that no control action is executed without my authorization.
\item As a Building Resident, I want to monitor the affected zone after an approved control action is executed so that I can determine whether the environmental condition improves.
\item As a Building Resident, I want to review previous alerts, approval decisions, and executed control actions so that I can review the history of environmental incidents in a zone.
\end{enumerate}

\subsubsection*{Persona 2 -- HVAC Maintenance Technician}

\keephead{Usage Scenario}
When an environmental condition requires technical investigation or maintenance, the HVAC Maintenance Technician reviews the affected zone, abnormal condition, relevant environmental readings, and alert details. The technician also reviews information about any control actions associated with the incident. Using this information, the technician identifies what requires inspection and examines the relevant sensor or HVAC equipment. The technician performs the necessary maintenance and records the work performed, its status, and whether the technical problem was resolved. After maintenance, the technician reviews updated environmental readings to determine whether the condition has improved.

\keephead{User Stories}
\begin{enumerate}[itemsep=3pt]
\item As an HVAC Maintenance Technician, I want to view the affected zone, abnormal condition, relevant environmental readings, and alert details so that I can determine what requires technical investigation.
\item As an HVAC Maintenance Technician, I want to view information about control actions associated with the environmental incident so that I know what actions have already been taken.
\item As an HVAC Maintenance Technician, I want to record the maintenance work performed, its status, and whether the technical problem was resolved so that the progress and outcome of the investigation are documented.
\item As an HVAC Maintenance Technician, I want to view updated environmental readings after maintenance so that I can determine whether the condition has improved.
\end{enumerate}
