# ZoneSense Lab Reports

**CS3151 – Software Engineering · Effat University · Fall 2026**
Instructor: Dr. Passent Elkafrawy

ZoneSense is a Smart Zone Environmental Monitoring and HVAC Control System. This repository holds the LaTeX source for each lab report. Every folder is a self-contained Overleaf project (`main.tex`, `preamble.tex`, `figures/`) with a compiled PDF.

| Lab | Folder | Topic |
|---|---|---|
| 1 | [Lab1_Market_Study](Lab1_Market_Study) | Market study, feasibility analysis, Business Model Canvas, literature review |
| 2 | [Lab2_User_Personas](Lab2_User_Personas) | User groups, personas, requirements mapping, scenarios and user stories |
| 3 | [Lab3_Requirements](Lab3_Requirements) | Functional and non-functional requirements, elicitation methods |
| 4 | [Lab4_Use_Cases_UML](Lab4_Use_Cases_UML) | Actors, use cases, traceability matrix, UML diagrams, domain model |
| 5 | [Lab5_Architecture_Design_Patterns](Lab5_Architecture_Design_Patterns) | Context diagram, C4 diagrams, architecture, Strategy/Observer/Adapter patterns |
| 6 | [Lab6_Project_Management](Lab6_Project_Management) | Backlog, MoSCoW, sprints, risks, milestones, Docker (Smart Event Management Platform) |
